# mcdr-devtools

Development tools for MCDReforged.
> PyPI package `mcdreforged` is necessary for this package to work.

This is a Python package, import it in your code as a dependency or just run it are both supported.

The main documentation is located in [MCDR DevTools Docs](https://docs.staringplanet.top/mcdr-devtools).
> Deployed by CloudFlare with GitHub Actions.

## Usage

Run `mcdr-devtools` or `mcdr-devtools -h` for command help messages.

Run `mcdr-devtools run` to enter the interactive TUI, then you can select to use one of the development tools. 

Run `mcdr-devtools create-plugin-metadata` or `mcdr-devtools meta` to create a new `mcdreforged.plugin.json` file. 

For more informations, read the docs.
