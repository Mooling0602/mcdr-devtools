# Rules for AI Agents

## Git

This git repository follows [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).

## Documentations & Comments

This project uses Sphinx for automatic documentation generation. For special comments called docstrings, we use reStructuredText format.

Sphinx codes are located in the `docs` folder. The `doc` folder is used to store the plain Markdown documentation files that are necessary and useful to reference.

Keep the content clear and concise, avoid unnecessary details. Read [prune-comments-and-docs.md](doc/prune-comments-and-docs.md) for more information.

## CI / CD

This project uses GitHub Actions for CI/CD. The `.github/workflows` folder contains the workflow files.
